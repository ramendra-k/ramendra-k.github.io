This project implemented real-time fire detection on a Raspberry Pi using image-processing features such as histogram, centroid, and variance analysis.

Highlights:

- Published as **"A Computer Vision-Based Fire Detection and Control System"** in *Springer — Fire Technology*
- Achieved **95.26% accuracy**, improving on prior methods by **7.95%**
- Designed for practical, low-cost deployment with embedded hardware constraints

**Stack:** Python, OpenCV, Raspberry Pi
