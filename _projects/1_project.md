HealthSenseAI is a fleet-scale health monitoring and self-heal platform built for more than 10,000 Windows endpoints. It replaced manual per-device debugging with centralized telemetry, causal diagnosis, and bounded remediation workflows.

Highlights:

- 24 health checkers with real-time telemetry ingestion and dashboarding
- Agentic repair flow: root-cause analysis → skill-scoped remediation → deterministic verification
- Circuit-breaker protection for AI backend resilience and a PII redaction layer for safer operations
- Achieved a **29% auto-fix rate across 19 issue types**

**Stack:** Python, Azure OpenAI, asyncio
