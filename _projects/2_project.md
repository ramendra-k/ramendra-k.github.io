PLE Echo is an AI onboarding assistant designed to reduce repeated knowledge-transfer overhead for senior engineers and help new team members ramp faster.

Highlights:

- Fine-tuned a **Mistral-7B** model with **LoRA/PEFT** on internal team documentation
- Built a **FAISS-indexed RAG pipeline** with **BGE-large embeddings** for retrieval quality
- Deployed the system as a lightweight web application for team-wide use

**Stack:** Python, PyTorch, Mistral-7B, Flask, FAISS
